## Como usar

1. Escolha o case na tabela e abra a pasta.
2. Leia o `LEIA-ME.md` da pasta: ele explica como rodar cada versão.
3. **Colab:** clique no notebook, depois em "Open in Colab" (ou abra pelo link
   `https://colab.research.google.com/github/adrielpereira-ai/cases-agro/blob/main/<pasta>/colab/<arquivo>.ipynb`).
4. Troque o município/estação na célula **"Configure aqui"** e rode.
